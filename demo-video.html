Problem

The black box for on-chain agents.

Record every prompt, tool call, decision, and transaction. Then replay the timeline and prove what changed.

Connect an agent

Six lines to make an agent replayable.

The SDK records the run. The MCP server gives agent-native recall, verify, and fork tools.

import { createReplay } from "replay";

const replay = createReplay({
  agentId: "meridian",
  runId: "rebalance-2026-06",
  backend
});

await replay.record({
  kind: "decision",
  summary: "Risk policy passed"
});
